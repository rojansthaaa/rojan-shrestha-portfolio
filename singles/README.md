# Add single photographs

Upload photos here and they appear on the **Singles** page in about 2–3
minutes. The newest photos show first.

1. Click **Add file → Upload files**.
2. Drag in your photos (JPG or PNG; big files are shrunk for you).
3. Click **Commit changes**.

## Optional: a caption and a description for Google

For a photo called `Two Trees.jpg`, also upload a plain-text file called
`Two Trees.txt` (same name) containing:

```
Title: Two trees
Alt: Two large trees side by side in a green field
```

- **Title** is shown under the photo (leave it out for no caption).
- **Alt** is not shown. It describes the photo for Google Images and for
  people using a screen reader. It's worth writing one line for each photo.

To remove a single photo later, ask for help or edit `content/singles.json`
and delete its entry.
