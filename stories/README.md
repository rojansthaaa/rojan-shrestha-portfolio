# Add a story to the website

Put a folder of photos here and the website adds the story by itself in about
2–3 minutes. You never touch any code.

## 1. Make a folder on your computer

Name it anything, for example `Kathmandu Floods`. Inside it put:

- **Your photos** (JPG or PNG). They appear in file-name order, so name them
  `01.jpg`, `02.jpg`, `03.jpg` ... Big camera files are fine — the website
  shrinks them for you.
- **Two photos side by side:** name them `03a.jpg` and `03b.jpg`.
- **A text file called `story.txt`** (plain text: in TextEdit choose
  *Format → Make Plain Text*, then save). Write it like this:

```
Title: Kathmandu Floods
Description:
Your text about the story goes here.

A blank line starts a new paragraph.
```

The text is optional. Without `story.txt` the folder name is used as the title.

## 2. Upload it

1. Open the **projects** folder (for personal projects) or the **editorial**
   folder (for editorial stories) here on GitHub.
2. Click **Add file → Upload files**.
3. **Drag your whole folder** into the page and wait for it to finish.
4. Click **Commit changes**.

That's it. Watch the **Actions** tab at the top of the repository: a green
tick means the story is live. Your website address for it will be the title
with no spaces, e.g. `rojanshrestha.com/kathmandufloods`.

## Later

- **Add photos:** upload more photos into the same folder (use new numbers
  so they come after the others).
- **Change the title or text:** open `story.txt` in the story's folder, click
  the pencil icon, edit, commit.
- **Remove a story:** delete its folder here. The story disappears from the
  website.

## Good to know

- Photos from an iPhone are often HEIC. Export them as JPG first, or they are
  skipped (the Actions log tells you which).
- GitHub accepts up to 100 files at once, 25 MB each. For bigger stories,
  upload in two batches into the same folder.
- Single photos that are not part of a story go in the **singles** folder.
