# Add tearsheets

Upload screenshots (or scans) of your published work here and they appear on
the **Tearsheet** page in about 2–3 minutes, newest first.

1. Click **Add file → Upload files**.
2. Drag in the screenshots (PNG or JPG) — big files are shrunk for you.
3. Click **Commit changes**.

## Name the publication and date (recommended)

For a screenshot called `cnn-nepal-election.png`, also upload a plain-text
file with the same name, `cnn-nepal-election.txt`, containing:

```
Publication: CNN
Date: March 2026
Link: https://edition.cnn.com/...
Alt: CNN article on Nepal's election, with a photograph by Rojan Shrestha
```

- **Publication** and **Date** are shown under the tearsheet. The page gets
  a filter button for each publication automatically.
- **Link** (optional) adds a "Read article" link in the enlarged view.
- **Alt** is not shown; it describes the page for Google and screen readers.
